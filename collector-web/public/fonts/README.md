# Typography

Inter Regular and SemiBold provide the interface typography. JetBrains Mono
Regular provides the data typography. These WOFF2 files are Latin subsets of
the locally hosted fonts used by the Integrity Satellite website, including
Latin extensions, punctuation, arrows, and the minus sign. Other characters
use the browser's system fallback fonts.

Font sources and licenses:

- [Inter](https://github.com/rsms/inter), [SIL Open Font License](Inter-OFL.txt).
- [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono),
  [SIL Open Font License](JetBrainsMono-OFL.txt).

The original name and copyright metadata are preserved in each subset.
